= SysML v2 Pilot Implementation - Temporary Fork

This repository is a temporary fork of the https://github.com/Systems-Modeling/SysML-v2-Pilot-Implementation[official SysML v2 Pilot Implementation].
*Its main goal is to contribute all developments back upstream so that this fork can be retired.*

In the meantime, it makes pending fixes and enhancements available to https://github.com/eclipse-syson/syson[Eclipse SysON].
SysON will gladly switch to the official repository once the changes it needs are available upstream.

== Purpose

This fork serves three purposes:

* Make fixes and enhancements available before they are integrated into the official repository.
* Provide a version that SysON can use in the meantime.
* Support the contribution of all developments in this fork back to the official repository, with the goal of making this fork unnecessary.

== Upstream Integration and Retirement

All developments made in this fork are intended to be contributed back to the official SysML v2 Pilot Implementation.
The official repository remains the long-term home for this work.

Once the changes needed by SysON are available upstream, SysON will gladly switch to the official repository and this fork can be retired.
The goal is to end the need for this fork as soon as upstream can meet SysON's needs.
